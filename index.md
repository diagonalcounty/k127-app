# K127

K127 is a Markdown notes app for iPad. Your notes are ordinary files in a folder on this device — a vault you can also open in another editor.

GitHub is optional. You can write with everything only on this iPad. When you want a remote copy, you can connect a git host you control, using a personal access token stored in the Keychain on this device.

K127 0.1.0 is a free early release. The core writing and GitHub paths work. Some views are still being polished, and you should not expect everything to be finished. This early release does not include AI on iPad.

K127 does not require an account with us. Notes stay on this device unless you connect a git host you control.
